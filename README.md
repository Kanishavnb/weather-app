# Weather App

Search any city and see the current weather and a 5-day forecast.

## Features
- City search using the Open-Meteo geocoding API
- Current temperature, conditions and wind
- 5-day forecast
- Celsius / Fahrenheit toggle
- Remembers your last city and unit with localStorage
- Error handling for unknown cities and network problems
- Responsive layout

## Built with
HTML, CSS, JavaScript (fetch, async/await)

Weather data by Open-Meteo.com
